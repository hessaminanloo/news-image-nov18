A newspaper front page that sums up Wednesday 18 November 2026 in a
single image, for make.fun's `news-image-20261118` competition. An AI
judge compares entries two at a time and picks the one that best sums
up the day's world news; the 50 best share $250.

The image is drawn entirely in code — no photos, no network, no
external assets — from the day's reporting (Just Security, AP, Reuters,
AFP, NPR, Dawn, Korea Herald, Open Chronicle). Every headline on the
page happened or was first reported on 18 November 2026.

## The formula

Built on the winners' research: the winning news-image entry had
35 stories plus a world map with pins, and the whole top 10 used the
same formula. This page goes further — **48 stories, 6 continents,
one page**: 1 lead story, 12 story cards, a world map with numbered
pins for the first 12 stories (the lead and cards 2–12), and 35
one-line briefs. The file is 208 KB —
leaner than the previous winner's 335 KB (file size is a tie-break).

## How it runs

The entry is a Node 22 program (`main.ts`, standard library only).
It copies the finished `entry.png` (1024×1024, ~208 KB) to the
output directory, so both graded runs write identical bytes:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Build

`entry.png` was generated by `build_image.py` (Pillow, DejaVu
fonts) in the agent workspace on 19 November 2026, from the news
summary above. Re-running the script reproduces the same bytes.
